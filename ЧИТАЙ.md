# «Вместе» — забота вдвоём 💞

Тихий трекер для двоих: вода, еда, сон, движение, витамины и самочувствие.
Без давления и без «ты должна». Мягкий режим — по кнопке.

Всё работает как обычный сайт: открывается в Chrome, ставится на главный экран,
живёт офлайн. Синхронизация — через Firebase Realtime Database.

---

## Что уже есть

| Экран | Что делает |
|---|---|
| **Сегодня** | кольцо воды, стаканы в один тап, еда, сон, активность, витамины, настроение, «кровь из носа», серия дней |
| **Вместе** | сегодняшний день партнёра, сердечки, записочки, быстрые фразы «попей водички» |
| **История** | календарь 35 дней, график воды, график кровотечений, резервная копия |
| **Настройки** | профиль, цели, список лекарств, комната, Firebase, экспорт/импорт |

Свои данные — только на телефоне. Обмен появляется, когда вы вдвоём в одной «комнате».

## Быстрый старт (5 минут, без Firebase)

1. Скопируйте папку `VMESTE` на телефон (она уже в `Download/VMESTE`).
2. Откройте `Download/VMESTE/index.html` в Chrome.
3. Введите имя → пользуйтесь.

Так данные живут **только на этом телефоне**. Чтобы видеть друг друга — нужен шаг ниже.

---

## Шаг 1. Firebase (один раз, на вашем аккаунте)

1. Зайдите на <https://console.firebase.google.com> → **Создать проект**
   (название любое, Google Analytics можно отключить).
2. Слева: **Build → Realtime Database → Создать базу данных**
   → выберите регион (например, `europe-west1`) → «Начать в заблокированном режиме».
3. Вверху базы скопируйте адрес. Он выглядит так:
   ```
   https://vmeste-7f3a-default-rtdb.europe-west1.firebasedatabase.app
   ```
4. Слева: **Build → Authentication → Get started → Sign-in method → Anonymous** → включить.
5. Вкладка **Rules** в Realtime Database → вставьте содержимое файла
   `firebase-rules.json` → **Publish**.
6. Настройки проекта (шестерёнка) → **General → Your apps → Web** (`</>`),
   если веб-приложения ещё нет — создайте. Скопируйте `apiKey` (начинается с `AIza…`).

Теперь вставьте два значения одним из двух способов:

**Способ А (удобнее):** откройте файл `js/config.js` и впишите
```js
window.VMESTE_CONFIG = {
  firebase: {
    databaseURL: 'https://…firebasedatabase.app',
    apiKey: 'AIza…'
  },
  room: ''
};
```
Тогда партнёру ничего вводить не нужно — Firebase уже внутри.

**Способ Б:** в приложении → Настройки → Firebase → вставить оба поля → «Подключить».

---

## Шаг 2. Комната для двоих

1. На своём телефоне: **Настройки → Комната → «Создать комнату»**.
   Появится код вида `K7QM2XPD` — он сразу копируется в буфер.
2. Передайте код партнёру любым способом (сообщением).
3. На её телефоне: Настройки → Комната → вписать код → **«Войти по коду»**.

Через несколько секунд в шапке появится «в сети», а во вкладке **Вместе** — её день.

---

## Шаг 3. Чтобы открывалось по ссылке (по желанию, GitHub Pages)

Так приложение получает нормальный адрес, устанавливается на главный экран,
работает офлайн и не зависит от папки в Downloads.

1. Создайте репозиторий, например `vmeste` (можно приватный — но Pages требует публичный
   на бесплатном тарифе; данные в коде не секретные, потому что всё в Firebase).
2. Загрузите туда **содержимое** папки `VMESTE`, а не саму папку:
   `index.html`, `styles.css`, `manifest.webmanifest`, `sw.js` и все `.js`/`.svg` — всё в корне.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**
   → Branch: `main`, папка `/ (root)` → **Save**.
4. Через минуту ссылка: `https://ваш-логин.github.io/vmeste/`.
5. Откройте её в Chrome на телефоне → меню ⋮ → **Добавить на главный экран**.

Установленное приложение умеет показывать уведомления о воде (пока открыто) и
не теряет данные офлайн.

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| В настройках «нет связи» | не включён Anonymous вход, или Rules не опубликованы, или неверный `databaseURL` |
| «Анонимный вход не разрешён» | Authentication → Sign‑in method → Anonymous → включить |
| Партнёр не появляется | коды комнат отличаются на одну букву; проверьте оба поля «Комната» |
| Данные не летят в обе стороны | у обоих должен быть настроен Firebase (лучше через `js/config.js`) |
| Старые данные не отправляются | Настройки → внизу «в очереди»; нажмите на значок синхронизации → «Переподключиться» |

Проверить вручную можно так: Настройки → Firebase → **«Проверить»**.
